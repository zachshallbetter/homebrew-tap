# Security Policy

## Reporting a vulnerability

Please report security issues privately, not in a public issue. Use GitHub private vulnerability reporting:

https://github.com/zachshallbetter/homebrew-tap/security/advisories/new

Include a description of the issue and its impact, and steps to reproduce.

This project has a solo maintainer. Reports are handled on a best-effort basis, with no response or fix time guaranteed (no SLA).

## Scope

This repository contains Homebrew formulae for `creative-mcp`, `adobe-mcp` and `blender-mcp`. Reports about a formula that points at the wrong source, carries a wrong checksum, or could cause an install to run unintended code are in scope. Vulnerabilities in the tools themselves should still be reported through the link above.
